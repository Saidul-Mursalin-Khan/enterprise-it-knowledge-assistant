# Software Installation and Administrator Access

**Document ID:** IT-004  
**Owner:** Endpoint Management  
**Version:** 1.0  
**Status:** Demo policy — fictional company data

## Approved software
Employees should install business software only from the company Software Portal.

## Requesting unlisted software
Software not listed in the portal requires manager approval and IT security review before installation. Include the business purpose and the software name in the request.

## Administrator access
Administrator access is not granted solely to install unapproved applications. Employees must not bypass device controls or use personal download sites to avoid the approval process.

## Help
If an approved application is missing from the portal or fails to install, open an IT Service Desk ticket with the application name and the error message.
